# Lumen — Photography Portfolio Website

A complete, modern, full-length photography portfolio website. Elegant dark/light theme, fully responsive, and packed with interactive features.

**Live Preview:** Open `index.html` in any modern browser.

---

## 🎯 Features

- **Hero Section** with dramatic full-screen imagery and smooth animations
- **About Section** with animated counters and experience badge
- **Filterable Portfolio Gallery** (Portrait, Landscape, Wedding, Commercial)
- **Lightbox** with keyboard navigation (Esc, ←, →)
- **Services Cards** with pricing and feature lists
- **Testimonials Slider** with auto-play
- **Contact Form** with success feedback
- **Dark / Light Theme Toggle** (preference saved in localStorage)
- **Mobile-first responsive design** + hamburger menu
- **Smooth scroll navigation** + active section highlighting
- **Preloader** and scroll-reveal animations

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/aicodepaswan-arch/photography-portfolio.git
   cd photography-portfolio
   ```

2. Open `index.html` in your browser  
   (or use a local server for best results):
   ```bash
   # Python
   python -m http.server 8000

   # VS Code Live Server extension also works great
   ```

3. Visit `http://localhost:8000`

## 🎨 Design Notes

- **Fonts:** Cormorant Garamond (serif headings) + Inter (body)
- **Color Palette:** Deep black backgrounds with warm gold accent (`#c9a962`)
- **Images:** High-quality Unsplash placeholders (replace with your own photos)
- **No frameworks** — pure HTML, CSS & vanilla JavaScript

---

## 🔧 Customization

| What to change              | Where                          |
|----------------------------|--------------------------------|
| Photographer name / brand  | `index.html` (logo, about, footer) |
| Photos                     | Replace Unsplash URLs in HTML  |
| Colors                     | CSS variables in `css/style.css` |
| Services & prices          | Services section in HTML       |
| Contact info               | Contact section in HTML        |
